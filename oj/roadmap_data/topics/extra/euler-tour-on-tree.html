Euler Tour on Tree

Mục tiêu

  • Biến cấu trúc cây thành một thứ tự tuyến tính bằng thời điểm vào/ra DFS.
  • Áp dụng mảng Euler để xử lý truy vấn trên cây con.
  • Kết hợp với Fenwick Tree hoặc Segment Tree cho các bài toán cập nhật/truy vấn nhanh.

Ý tưởng chính

Khi DFS trên cây, mỗi đỉnh u được gán thời điểm vào tin[u]. Toàn bộ các đỉnh thuộc cây con của u sẽ nằm liên tiếp trong đoạn [tin[u], tout[u]] nếu ta ghi nhận mỗi đỉnh một lần khi đi vào.

Mẫu cài đặt C++

int timer = 0;
vector<vector<int>> g;
vector<int> tin, tout, order;

void dfs(int u, int parent) {
    tin[u] = ++timer;
    order[timer] = u;
    for (int v : g[u]) {
        if (v == parent) continue;
        dfs(v, u);
    }
    tout[u] = timer;
}

Bài toán thường gặp

  • Tính tổng giá trị trong cây con của một đỉnh.
  • Cập nhật giá trị một đỉnh và truy vấn cây con.
  • Đếm số đỉnh thỏa điều kiện trong subtree.
  • Làm nền tảng cho LCA, HLD hoặc DSU on Tree.
