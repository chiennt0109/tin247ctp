1. Đặt vấn đề

Bài toán mở đầu.
Một học sinh được công nhận đạt nếu điểm thi từ 5 trở lên. Nếu điểm dưới 5, học sinh chưa đạt. Nhập điểm và in kết quả.

Chương trình không thể luôn in cùng một nội dung. Nó phải kiểm tra:

score ≥ 5 ?

Nếu đúng

Chạy nhánh in Đạt.

Nếu sai

Chạy nhánh in Chưa đạt.

1.1. Mở rộng bài toán

Nếu cần phân loại:

  • Điểm từ 8 đến 10: Giỏi.
  • Điểm từ 6.5 đến dưới 8: Khá.
  • Điểm từ 5 đến dưới 6.5: Đạt.
  • Dưới 5: Chưa đạt.
Lúc này một if-else chưa đủ; cần chuỗi if - else if - else và phải sắp xếp điều kiện đúng thứ tự.

3. Các cấu trúc rẽ nhánh

if đơn

if (temperature < 10) {
    cout << "Mac ao am";
}

Không có hành động riêng khi điều kiện sai.

if – else

if (score >= 5) {
    cout << "Dat";
} else {
    cout << "Chua dat";
}

Chính xác một trong hai nhánh chạy.

else-if chain

if (score >= 8) {
    cout << "Gioi";
} else if (score >= 6.5) {
    cout << "Kha";
} else {
    cout << "Khac";
}

Nhánh đúng đầu tiên được chọn.

5. Toán tử logic: &&, ||, !

AND – &&

Đúng khi cả hai điều kiện đúng.

age >= 18 && hasId

OR – ||

Đúng khi ít nhất một điều kiện đúng.

isTeacher || isAdmin

NOT – !

Đảo giá trị Boolean.

!isEmpty

Short-circuit

Với &&, nếu vế trái false thì vế phải không cần chạy. Với ||, nếu vế trái true thì vế phải không cần chạy.

5.1. Bảng chân trị tương tác


Ứng dụng short-circuit: i < n && a[i] == x sẽ không truy cập a[i] nếu i >= n.

6. Mô phỏng else-if và thứ tự điều kiện

Thứ tự sai: 
if (score >= 5) cout << "Dat";
else if (score >= 8) cout << "Gioi";
Điểm 9 đã thỏa score >= 5, nên nhánh Giỏi không bao giờ được chạy.

9. Giải thích code

9.1. Vì sao chuỗi else-if chỉ chạy một nhánh?

Chương trình kiểm tra từ trên xuống. Khi gặp điều kiện đúng đầu tiên, nó chạy nhánh đó rồi bỏ qua các nhánh còn lại.

9.2. Vì sao phải kiểm tra dữ liệu không hợp lệ trước?

Điểm −1 cũng thỏa điều kiện “dưới 5”, nhưng đây không phải điểm hợp lệ. Cần tách lỗi input khỏi kết quả phân loại.

9.3. Vì sao điều kiện điểm phải sắp từ cao xuống thấp?

Điểm 9 đồng thời thỏa ≥5, ≥6.5 và ≥8. Kiểm tra mốc cao trước để chọn đúng nhóm cụ thể nhất.

9.4. Vì sao max ba số dùng hai if độc lập?

Sau khi so sánh với b, giá trị answer có thể thay đổi; ta vẫn phải tiếp tục so sánh với c. Hai kiểm tra không loại trừ nhau.

9.5. Có viết 0 ≤ x ≤ 10 trong C++ được không?

Không. Biểu thức 0 <= x <= 10 được tính từ trái sang phải và cho kết quả sai về ý nghĩa. Phải viết 0 <= x && x <= 10.

9.6. Có nên luôn dùng dấu ngoặc nhọn?

Nên dùng, kể cả khi nhánh chỉ có một lệnh. Điều này tránh lỗi khi bổ sung câu lệnh và làm rõ else thuộc về if nào.

10. Lỗi thường gặp

  • Dùng = thay cho ==.
  • Viết 0 <= x <= 10.
  • Sắp điều kiện else-if từ rộng đến hẹp.
  • Quên xử lý giá trị biên như 5, 6.5, 8.
  • Đặt dấu chấm phẩy sau if (condition);.
  • Không dùng ngoặc nhọn và khiến else gắn với if gần nhất.
  • So sánh số thực bằng == trong bài cần sai số.
  • Dùng nhiều if độc lập khi các nhánh phải loại trừ nhau.
  • Quên kiểm tra input ngoài miền hợp lệ.
